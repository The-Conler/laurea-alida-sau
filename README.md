# Invito — Laurea di Alida Sau

Pagina-invito con un unico link per tutti gli ospiti. Le risposte RSVP si raccolgono nel database Notion **RSVP · Laurea di Alida Sau**.

## Come cambiare il nome

Apri `index.html` e modifica questa costante, all’inizio dello script:

```js
const GRADUATE_NAME = "Alida Sau";
```

Aggiorna automaticamente il titolo della pagina, il titolo per l’anteprima WhatsApp e il nome in grande. Se cambi il nome, rigenera anche `og-image.png` (anteprima di condivisione).
